## Terminal流し込み問題

拡張機能開発では、以下のようにPowerShellを実行する方法があります。

```ts
// アクティブなターミナルを取得、なければ新規作成
const terminal = vscode.window.activeTerminal ?? vscode.window.createTerminal();

terminal.show();
terminal.sendText(command);
```

これは、ターミナルを開いてテキストを流し込む方法です。
手軽ですが、いくつか弱点があります。

- VSCode側が管理しにくい
- タスク管理がしにくいため、後続処理での終了判定などに困る
- テキストを流し込むため、自然なスクリプト開発の感覚と異なる

## スクリプトランナー

都度パス解決～スクリプトファイルの実行を書くのは冗長なので、以下のツールにまとめました。

```ts
import * as process from "node:process";
import * as vscode from "vscode";

// TODO: [TEMPLATE] ↓ 任意の識別名をつけてください
const TASK_TYPE = "extension-template.b724f99c-224d-4b47-824b-3af95d45e921.ShellScript";

export async function runPowerShellScript(
    scriptUri: vscode.Uri,
    taskName: string
): Promise<void> {
    const isSameTask = vscode.tasks.taskExecutions.some(t =>
        t.task.definition.type === TASK_TYPE &&
        t.task.name === taskName
    );

    if (isSameTask) {
        vscode.window.showErrorMessage(`既に '${taskName}' が実行中です`);
        return;
    }

    const isWindows = process.platform === "win32";
    const shellPath = isWindows ? "powershell.exe" : "pwsh";

    const task = new vscode.Task(
        { type: TASK_TYPE },
        vscode.TaskScope.Workspace,
        taskName,
        "shell script",
        new vscode.ShellExecution(
            shellPath,
            [
                "-NoProfile",
                "-ExecutionPolicy", "Bypass",
                "-File", scriptUri.fsPath
            ]
        )
    );

    await vscode.tasks.executeTask(task);
}
```

上記の内容を`/src/lib/powerShellRunner.ts`などのファイルにしてください。


## スクリプト実行方法

`extension.ts`で直接実行する例を示します。

```ts
import * as vscode from 'vscode';
import { AssetStorage } from './assets/AssetStorage';
import { runPowerShellScript } './lib/powerShellRunner';


export function activate(context: vscode.ExtensionContext) {
    console.log(`${EXTENSION_NAME} activated.`);
    vscode.window.showInformationMessage(`${EXTENSION_NAME} activated.`);

    const asset = new AssetStorage(context);

    const disposable = vscode.commands.registerCommand('vscode-extension-template.executePwshSample', async () => {
        // 第1引数にUriを書き、第2引数にはタスク名を書きます
        await runPowerShellScript(
            asset.getUri("powerShell/scripts/sample.ps1"),
            "SAMPLE TASK"
        );
    });

    context.subscriptions.push(disposable);
}
```

この処理では、以下のことが自動的に行われます。

- 2重タスクの検知・抑制
- PowerShell実行のボイラーテンプレート
- VSCodeのタスクとして実行
